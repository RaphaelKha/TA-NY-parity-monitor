# TA–NY Parity Monitor

**מניה אחת, שתי בורסות, שני מחירים.** ארבע חברות ישראליות נסחרות גם בתל אביב וגם בניו יורק. לאחר המרה לדולרים, שני המחירים אמורים להיות שווים. הפרויקט הזה מודד, דקה אחר דקה, כמה הם מתרחקים זה מזה, והאם הפער נשאר אי פעם רחב מספיק, ולמשך זמן מספיק, כדי לממן עסקה הלוך-חזור.

זהו פרויקט מחקר אישי. הקוד אינו מבצע פקודות מסחר, ואין באמור כאן ייעוץ השקעות.

## הרעיון בנוסחה אחת

לכל דקה *t* שבה המניה נסחרה **בשתי** הבורסות:

</div>

```math
g_t \;=\; 10^4 \left( \frac{P^{\mathrm{NY}}_t}{\dfrac{k \, P^{\mathrm{TA}}_t}{100 \, S_t}} \;-\; 1 \right)
```

<div dir="rtl">

| סימן | משמעות |
|---|---|
| $P^{\mathrm{NY}}_t$ | העסקה האחרונה בניו יורק, בדולרים |
| $P^{\mathrm{TA}}_t$ | העסקה האחרונה בתל אביב, באגורות |
| $S_t$ | שער הדולר/שקל (שקלים לדולר), ציטוט אחרון שגילו עד 5 דקות |
| $k$ | מספר המניות בתל אביב לכל מניה בניו יורק (1 בכל ארבעת הצמדים) |
| $g_t$ | הפער, בנקודות בסיס (נקודת בסיס = 0.01%) |

פער קטן ויציב הוא תקין: עמלות, מיסוי והכיוון הרגיל של זרימות הכסף. מה שחשוב הוא **התרחקות מהפער הרגיל**, הנמדדת מול החציון של 300 הדקות המשותפות הקודמות:

</div>

```math
d_t \;=\; g_t \;-\; \mathrm{median}\left(g_{t-300}, \dots, g_{t-1}\right)
```

<div dir="rtl">

עסקה דורשת לבצע את שתי הרגליים לפני שהפער נסגר. לכן **אפיזודה** נספרת רק אם הסטייה נשארת מעבר לעלות ההלוך-חזור *c*, באותו כיוון, לפחות 3 דקות רצופות:

</div>

```math
|d_s| > c \quad\text{and}\quad \mathrm{sign}(d_s) \text{ constant} \qquad \text{for all } s \in [t,\, t+2], \qquad c \in \{20, 40, 60\} \text{ bp}
```

## הקוד

כל החישוב הוא שתי פונקציות ב-[`parity_track.py`](parity_track.py). הפער, בדקות שבהן שתי הרגליים אכן נסחרו:

</div>

```python
def pair_gaps(us, tase, fx, ratio, bias_window):
    df = pd.concat({"us": us["close"], "us_v": us["volume"], "tase": tase["close"], "tase_v": tase["volume"]},
                   axis=1, join="inner")
    df = df[(df.us_v > 0) & (df.tase_v > 0)]  # both legs traded in that minute: no stale price
    # USD/ILS quotes have holes: last quote at most 5 minutes old
    df["fx"] = fx["close"].reindex(df.index, method="ffill", tolerance=pd.Timedelta("5min"))
    df = df.dropna(subset=["fx"])
    df["gap_bps"] = (df.us / (df.tase / 100 / df.fx * ratio) - 1) * 1e4
    df["bias_bps"] = df.gap_bps.rolling(bias_window, min_periods=30).median().shift()
    df["dev_bps"] = df.gap_bps - df.bias_bps
    return df.dropna(subset=["dev_bps"])
```

<div dir="rtl">

הפקודה `.shift()` שומרת את הפער הרגיל בעבר בלבד: דקה *t* לעולם אינה מושווית לחציון שכולל אותה.

האפיזודות, כרצפים של דקות עוקבות באותו צד של הסף:

</div>

```python
def episodes(dev, threshold):
    """Lengths in minutes of the runs of consecutive minutes with |dev| > threshold on the same side."""
    x = dev.asfreq("1min")  # a missing minute breaks the run
    side = (x > threshold).astype(int) - (x < -threshold).astype(int)
    run_id = (side != side.shift()).cumsum()
    return side[side != 0].groupby(run_id[side != 0]).size()
```

## פרטי השיטה

### הצמדים

| ניו יורק | תל אביב | יחס *k* |
|---|---|---|
| TEVA | TEVA.TA | ‏1 |
| NICE | NICE.TA | ‏1 |
| ESLT | ESLT.TA | ‏1 |
| ICL | ICL.TA | ‏1 |

המחירים עצמם מאשרים את היחס. עם *k* = 1, הפער החציוני הוא בין ‎−2 ל-‎−13 נקודות בסיס בכל ארבעת הצמדים. יחס של 2 היה מביא אותו לסביבות ‎−5,000 נקודות בסיס, ויחס של ½ לסביבות ‎+10,000: כל יחס מניות אחר היה מופיע כפער של אלפי נקודות בסיס.

צ'ק פוינט (CHKP) אינה נסחרת בתל אביב, ולכן אינה כלולה.

### חלון המסחר המשותף

שתי הבורסות פתוחות במקביל רק לזמן קצר בכל יום:
- כ**שעה** (13:30–14:30 UTC) עד 23 באוקטובר;
- כ**שעתיים** (13:30–15:30 UTC) מאז המעבר של ישראל לשעון חורף ב-25 באוקטובר;
- שוב כשעה החל מ-1 בנובמבר, כשארה"ב עוברת לשעון חורף.

ביום שישי תל אביב נסגרת לפני שניו יורק נפתחת: אין חלון משותף.

### מתי נקבעה השיטה

השיטה הזאת (הנוסחה, החציון של 300 דקות, כלל 3 הדקות, הספים 20/40/60 נקודות בסיס) פורסמה לראשונה ב-**27 באוקטובר 2026 בשעה 08:53 UTC**, לפני תוצאות הבחירות, כחלק 2 של [election-market-collect](https://github.com/RaphaelKha/election-market-collect) (קומיט `252fd12`). היא עברה למאגר הזה ב-29 באוקטובר 2026 ללא שינוי. הגרפים נוספו ב-29 באוקטובר.

### מגבלות

- הפערים מחושבים לפי **מחיר העסקה האחרונה** בכל דקה, ולא לפי הצעות הקנייה והמכירה. חלק מהפערים של דקה אחת הם רק קפיצה של העסקאות בין מחיר הקנייה למחיר המכירה, ולכן ספירות האפיזודות הן **חסם עליון**.
- שער החליפין הוא ציטוט הדולר/שקל של Yahoo, ולא בהכרח שער שאפשר לבצע בו עסקה.
- יחסי המניות מאושרים מתוך המחירים (ראו הצמדים), ולא מתוך דיווחי החברות.
- נתוני Yahoo Finance אינם רשמיים ועלולים להכיל חורים; Yahoo גם מתקנת חלק מהנרות שבעבר, כך שהרצה חוזרת יכולה להזיז מעט את המספרים של יום מסוים.
- 14 ימי מסחר, כשעה כל אחד עד 23 באוקטובר: מדגם קצר.
